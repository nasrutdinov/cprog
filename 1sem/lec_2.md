# Теория: обход графов и деревьев (DFS, BFS)

## Основные понятия

- **Граф** — набор вершин (узлов) и рёбер между ними. Бывает ориентированным/неориентированным, взвешенным/невзвешенным.
- **Дерево** — связный ациклический граф. В контексте обходов часто рассматривают бинарные деревья.
- **Обход (traversal)** — систематическое посещение всех вершин графа/дерева ровно один раз (или по заданному правилу).

---

## Обход в глубину (Depth‑First Search, DFS)

**Идея:** максимально углубляться по одной ветви, пока не упрёмся, затем возвращаться (backtracking) и пробовать другие направления.

### Для дерева (бинарное дерево)

Три классических порядка:

- **Pre-order (прямой):** узел → левое поддерево → правое поддерево.  
  Применение: копирование дерева, сериализация.
- **In-order (центральный):** левое → узел → правое.  
  Для BST даёт отсортированную последовательность ключей.
- **Post-order (обратный):** левое → правое → узел.  
  Применение: удаление дерева (сначала дети), вычисление выражений.

### Для графа

Чтобы избежать циклов, используют массив посещённых вершин (`visited`). Для ориентированных графов дополнительно применяют три состояния:
- `0` (белый) — не посещена;
- `1` (серый) — в текущем стеке рекурсии (активна);
- `2` (чёрный) — полностью обработана.  
Цикл есть, если в процессе DFS встречаем серую вершину.

---

## Реализация DFS

### Рекурсивный DFS (граф)

```cpp
void dfs(int u, const std::vector<std::vector<int>>& g, std::vector<bool>& visited) {
    visited[u] = true;
    // обработка u
    for (int v : g[u]) {
        if (!visited[v]) {
            dfs(v, g, visited);
        }
    }
}
```

### Итеративный DFS (стек)

```cpp
void dfs_iterative(int start, const std::vector<std::vector<int>>& g, std::vector<bool>& visited) {
    std::stack<int> st;
    st.push(start);

    while (!st.empty()) {
        int u = st.top();
        st.pop();

        if (visited[u]) continue;
        visited[u] = true;
        // обработка u

        for (auto it = g[u].rbegin(); it != g[u].rend(); ++it) {
            if (!visited[*it]) {
                st.push(*it);
            }
        }
    }
}
```

---

## Обход в ширину (Breadth‑First Search, BFS)

**Идея:** посещать вершины по уровням (сначала все соседи стартовой, затем их соседи и т.д.). Реализуется через очередь.

**Применение:** поиск кратчайшего пути в невзвешенном графе, построение уровней дерева, топологическая сортировка (Kahn).

```cpp
void bfs(int start, const std::vector<std::vector<int>>& g, std::vector<bool>& visited) {
    std::queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        // обработка u

        for (int v : g[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```

---

## Сложность

- Время: $O(V + E)$ для графа, $O(N)$ для дерева.
- Память: $O(V)$ под `visited`, плюс $O(h)$ под стек/очередь (в худшем случае $O(V)$).

3. После построения вывести дерево в трёх порядках обхода для проверки.

**Дополнительно:**
- Обратный метод: `serializeToLeetCodeArray` (дерево → массив).
- Валидация входных данных (пустой массив, некорректный формат).

**Требования:**
- Корректная обработка `null` на любом уровне.
- Учёт неполных массивов (лишние `null` в конце).

**Критерии оценки:**
- Построение дерева — 4 балла.
- Корректность обходов — 3 балла.
- Обратная сериализация — 2 балла.
- Валидация — 1 балл.

**Шаблон кода:**

```cpp
#include <vector>
#include <string>
#include <queue>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class TreeBuilder {
public:
    static TreeNode* buildFromLeetCodeArray(const std::vector<std::string>& nodes) {
        if (nodes.empty() || nodes[0] == "null") return nullptr;

        TreeNode* root = new TreeNode(std::stoi(nodes[0]));
        std::queue<TreeNode*> q;
        q.push(root);

        int i = 1;
        while (!q.empty() && i < static_cast<int>(nodes.size())) {
            TreeNode* current = q.front();
            q.pop();

            // Левый потомок
            if (i < static_cast<int>(nodes.size()) && nodes[i] != "null") {
                current->left = new TreeNode(std::stoi(nodes[i]));
                q.push(current->left);
            }
            ++i;

            // Правый потомок
            if (i < static_cast<int>(nodes.size()) && nodes[i] != "null") {
                current->right = new TreeNode(std::stoi(nodes[i]));
                q.push(current->right);
            }
            ++i;
        }
        return root;
    }
};
```
