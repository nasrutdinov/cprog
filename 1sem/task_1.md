## Лабораторная работа №1. Класс `Vector` (аналог `std::vector<int>`)

**Цель:** научиться управлять динамической памятью, реализовать правило пяти, корректно обрабатывать исключения и перегрузку операторов.

**Требования к реализации:**
- Хранить элементы в динамическом массиве (`int*`), отслеживать `size` и `capacity`.
- Конструкторы:
  - по умолчанию (пустой вектор),
  - от размера `Vector(size_t n)` (элементы инициализируются нулём),
  - от списка инициализации `Vector(std::initializer_list<int>)`.
- Правило пяти: конструктор копирования, оператор присваивания, конструктор перемещения, оператор присваивания с перемещением, деструктор.
- Методы:
  - `size()`, `capacity()`.
  - `push_back(int value)`: при нехватке места увеличивать ёмкость (например, в 2 раза).
  - `pop_back()`: удалить последний элемент.
  - `at(size_t index)`: доступ с проверкой границ, выбрасывать `std::out_of_range` при ошибке.
  - `operator[](size_t index)`: доступ без проверки границ.
  - `clear()`: очистить вектор (размер 0, ёмкость сохраняется).
  - `reserve(size_t new_capacity)`: увеличить ёмкость, если нужно.
- Перегрузка операторов:
  - `friend std::ostream& operator<<(std::ostream&, const Vector&)` — вывод через пробел.
  - `operator==` и `operator!=` — поэлементное сравнение.
- Исключения и корректность:
  - Класс должен быть безопасен при выбросах исключений (RAII).
- Тесты:
  - Проверить копирование и перемещение (убедиться, что после перемещения исходный вектор пуст).
  - Протестировать рост ёмкости при `push_back`.
  - Проверить обработку выхода за границы через `at`.

**Срок сдачи:** Неделя 3 - 24 сентября

## Лабораторная работа №2. Класс `Matrix` (шаблонная матрица)

**Цель:** освоить шаблоны, многомерные структуры, перегрузку арифметических операторов.

**Требования к реализации:**
- Шаблонный класс `Matrix<typename T, size_t Rows, size_t Cols>`.
- Хранение данных — плоский массив `T[Rows * Cols]`.
- Конструкторы: по умолчанию (заполняет нулями), от `std::initializer_list` (если возможно) или отдельным методом.
- Операторы:
  - сложение/вычитание матриц одинакового размера,
  - умножение матрицы на скаляр,
  - умножение матриц (если размеры совместимы).
- Метод `transpose()` — возвращает транспонированную матрицу.
- `operator()` для доступа по индексам `(row, col)` с проверкой границ.
- Вывод в поток `operator<<`.
- Тесты:
  - Проверка сложения и умножения матриц.
  - Проверка корректности транспонирования.
  - Проверка обработки выхода за границы.

**Срок сдачи:** Неделя 3 - 25 сентября.
